# AbsatmatMC SMP

## Info

AbsatmatMC is a peaceful SMP hosted on minehut. I don't know why I'm making this sound like an ad when this is purely for listing rules of the server. The server is owned by GameMaster9997 on Minecraft, and it is Java and Bedrock crossplay. The server has a 4-hour daily time limit so preferably play together.

**World Difficulty:** Normal
**Keep Inventory:** Definitely Not
**Version:** Java 1.20.6 Paper
**End Dimension Open:** Not yet (lemme disable it)

### How to join (Java)

1. Minecraft -> Multiplayer -> Add Server
2. Connect to minehut with mc.minehut.com and any server name
3. In chat, type */join AbsatmatMC*

### How to join (Bedrock)

1. Minecraft -> Play -> Servers -> Add Server
2. Connect to minehut with bedrock.minehut.com and a port of: 19132
3. In chat, type */join AbsatmatMC*

### Why I can't join

The server has a whitelist, so I (GameMaster9997) need to whitelist you before you can join the server. However, minehut is a little stupid so you need to JOIN the server so that minehut will acknowledge your existence, allowing me to whitelist you. This shouldn't be a problem for too many but if you're new and you want to join you have to schedule an appointment so I can temporarily disable the whitelist to let you join (bad things happen without a whitelist).

## Rules

We have a lot of rules for the server, most of them have been voted in by the members.

### Very punishable rules

* No **entity "machines" unless it is manual**. Definition of manual: Every activation is triggered by a lever or button.
* No **griefing** or **stealing** or **robbing** or **putting** _birch planks_ in people's chests.
* No **illegal duping** _EXCEPT_ for tnt, gravity block (sand), or carpet duping.
* No **lag machines** because this thing runs on 1gb of ram (1/4 of a chromebook).
* No **XRAY or unfair mods** (fullbright allowed).

### Still punishable rules

* No **excessive farm afking** because there's a time limit.
* No **elytras unless you're in the end**. This is partially to make exploring more fun but also to make sure the server doesn't crash (mainly the latter).
* No **abusing community chests or farms**, specifically robbing everything they own.
* No **netherite armor**. You **can** have netherite tools but just **no netherite armor**.
* No using **chunkbase or any tools that utilize the world seed** to gain an unfair or fair advantage.
